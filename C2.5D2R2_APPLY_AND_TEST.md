# Apply, test, commit, and prove Luna C2.5D2R2

## 1. Verify the branch

```bash
cd ~/GitHub/Luna-UI

git switch a1.1-measured-audit
git pull --ff-only

git rev-parse HEAD
git status --short
```

Expected HEAD:

```text
0e187d03fda59be094ed1746bb2282017cba8991
```

The status must be clean before extraction.

## 2. Extract the repository overlay

```bash
unzip -o \
  ~/Downloads/Luna-UI-C2.5D2R2-Repository-Overlay.zip \
  -d .
```

The archive adds patch, documentation, and verification files. It does not
contain `.git`, `.build`, dependency copies, or generated build products.

## 3. Apply the guarded source repair

```bash
./scripts/apply-c2.5d2r2.sh
```

The script checks the branch, exact pre-repair commit, exact source blobs, and
tracked-tree cleanliness before applying anything.

Inspect the real source diff:

```bash
git diff -- \
  Sources/LunaHostCore/LunaFrameRuntime.swift \
  Sources/LunaUITestApp/DemoSharedRenderer.swift

./scripts/verify-c2.5d2r2-working-tree.sh
```

## 4. Focused validation

```bash
swift test \
  --filter LunaC25D2PartialDamageTests

swift test \
  --filter LunaC25DFramePathDiagnosticsTests
```

## 5. Full validation

```bash
swift build
swift test
./scripts/validate-iteration.sh
```

## 6. Native acceptance

```bash
swift run LunaUITestApp -- --kitchen-sink
swift run LunaUITestApp -- --editor
```

Use `docs/C2.5D2R2_NATIVE_ACCEPTANCE.md` as the required checklist.

## 7. Stage every required file

```bash
git add \
  Sources/LunaHostCore/LunaFrameRuntime.swift \
  Sources/LunaUITestApp/DemoSharedRenderer.swift \
  patches/C2.5D2R2_LUNA_VERIFIED_RUNTIME_INTEGRATION.patch \
  scripts/apply-c2.5d2r2.sh \
  scripts/apply-exact-unified-diff.py \
  scripts/remove-withdrawn-c2.5d3.sh \
  scripts/verify-c2.5d2r2-working-tree.sh \
  scripts/verify-c2.5d2r2-staged.sh \
  scripts/verify-c2.5d2r2-committed.sh \
  docs/C2.5D2R2_VERIFIED_RUNTIME_INTEGRATION.md \
  docs/C2.5D2R2_V2_PATCH_APPLICATION_REPAIR.md \
  docs/C2.5D2R2_NATIVE_ACCEPTANCE.md \
  C2.5D2R2_BASELINE.md \
  C2.5D2R2_APPLY_AND_TEST.md
```

Prove that the runtime files—not only the documentation—are staged:

```bash
./scripts/verify-c2.5d2r2-staged.sh

git diff --cached --check
git diff --cached --stat
```

The staged stat must list:

```text
Sources/LunaHostCore/LunaFrameRuntime.swift
Sources/LunaUITestApp/DemoSharedRenderer.swift
```

## 8. Commit and verify the committed blobs

```bash
git commit -m \
  "fix(render): commit verified C2.5D2 partial damage"

./scripts/verify-c2.5d2r2-committed.sh
```

Only push after the committed verification succeeds:

```bash
git push origin a1.1-measured-audit
```

Wait for Luna CI to pass before advancing Moth's Luna submodule.
