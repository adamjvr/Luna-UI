Native checks:

```bash
swift run LunaUITestApp -- --kitchen-sink
swift run LunaUITestApp -- --editor
```

In Kitchen Sink mode, verify:

- the first frame builds the static cache without beginning mid-animation;
- subsequent animation-only frames are smooth;
- typing or opening an overlay causes a full frame;
- closing the overlay returns to cached animation;
- resizing causes one or more full frames, then returns to cached animation.
