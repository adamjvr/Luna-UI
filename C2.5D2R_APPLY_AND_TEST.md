# Apply and validate Luna C2.5D2R

```bash
cd ~/GitHub/Luna-UI
git switch a1.1-measured-audit
git pull --ff-only
git status --short
```

The status output should be empty.

```bash
unzip -o \
  ~/Downloads/Luna-UI-C2.5D2R-Repository-Overlay.zip \
  -d .

git apply --recount --check \
  patches/C2.5D2R_LUNA_RUNTIME_INTEGRATION.patch

git apply --recount \
  patches/C2.5D2R_LUNA_RUNTIME_INTEGRATION.patch
```

Verify that the runtime source—not only the primitives and tests—changed:

```bash
./scripts/verify-c2.5d2r-integration.sh
git diff --check
git diff --stat
```

Focused tests:

```bash
swift test \
  --filter LunaC25D2PartialDamageTests

swift test \
  --filter LunaC25DFramePathDiagnosticsTests
```

Complete validation:

```bash
swift build
swift test
./scripts/validate-iteration.sh
```

Native acceptance:

```bash
swift run LunaUITestApp -- --kitchen-sink
```

Confirm:

- cold launch produces a complete frame and static cache;
- steady movement reports `partialDamage`, not `cachedAnimation`;
- damaged-region count is normally three: old square, new square, HUD;
- the scene-layout timing becomes zero or absent on steady partial frames;
- opening a menu or overlay forces `fullScene`;
- closing the overlay returns to `partialDamage`;
- resize rebuilds once and returns to `partialDamage`;
- the square leaves no trails or stale pixels.

Also run the editor baseline:

```bash
swift run LunaUITestApp -- --editor
```

Stage the actual integration files:

```bash
git add \
  Sources/LunaHostCore/LunaFrameRuntime.swift \
  Sources/LunaUITestApp/DemoSharedRenderer.swift \
  scripts/verify-c2.5d2r-integration.sh \
  docs/C2.5D2R_RUNTIME_INTEGRATION_REPAIR.md \
  docs/C2.5D2R_BRANCH_CLOSEOUT.md \
  C2.5D2R_BASELINE.md \
  C2.5D2R_APPLY_AND_TEST.md
```

Required staging guard:

```bash
for required in \
  Sources/LunaHostCore/LunaFrameRuntime.swift \
  Sources/LunaUITestApp/DemoSharedRenderer.swift
do
  git diff --cached --name-only | grep -Fxq "$required" || {
    printf 'error: required integration file is not staged: %s\n' "$required" >&2
    exit 1
  }
done
```

Commit and push:

```bash
git diff --cached --check
git diff --cached --stat

git commit -m \
  "fix(render): complete C2.5D2 partial-damage integration"

git push origin a1.1-measured-audit
```

Do not merge Luna to `main` until the paired Moth repair has been validated.
