# C2.5C — Indexed Visual-Row Planning

This checkpoint adds a document-level prefix index mapping logical lines to global visual rows.
Construction is O(lines), logical-line span lookup is O(1), global row lookup is O(log lines), and viewport planning is O(1). Only visible rows plus bounded overscan are materialized.

This is the contract required to replace the current whole-document `VisualSegment` array. The following integration commit should route `LunaStaticTextView.layout()`, scrolling, and caret visibility through this index.
