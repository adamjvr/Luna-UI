# A1.1R Luna Performance Investigation

This corrective checkpoint follows the committed A1.1 audit recorder. Native
acceptance still reports sluggish behavior in both Luna test-application modes.
A1.1R adds a deterministic headless probe for the two currently supported source
hypotheses without changing production behavior:

1. whole-document static-text layout scales with total logical/visual rows rather
   than visible rows;
2. restoring a complete CPU framebuffer for a small animated change produces
   full-frame memory traffic before SDL upload/presentation.

Run:

```bash
./scripts/run-a1.1r-performance-investigation.sh
```

Outputs:

- `.build/a1.1r-luna-investigation/LUNA_A1.1R_PERFORMANCE_REPORT.json`
- `.build/a1.1r-luna-investigation/LUNA_A1.1R_TEXT_LAYOUT.csv`

The probe intentionally does not report SDL upload, `SDL_RenderCopy`, VSync wait,
or `SDL_RenderPresent` timing. Those stages require a native profiler or later
explicit host instrumentation. Timing observations are not pass/fail thresholds.
