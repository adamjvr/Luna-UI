# C2.5D2R2 — verified Luna runtime integration

C2.5D2 supplied region-copy primitives and frame-path diagnostics. The first
C2.5D2R delivery also supplied the intended runtime patch, but the final commit
did not contain the two modified runtime source files.

C2.5D2R2 corrects both the runtime and the delivery guard.

## Runtime behavior

On a warm Kitchen Sink animation frame with only `.animation` invalidation:

1. cache eligibility is decided before complete scene layout is rebuilt;
2. the animation clock advances;
3. previous and current moving-block bounds are calculated;
4. the HUD is included in the damage set;
5. only those regions are restored from the static backing framebuffer;
6. dynamic proof surfaces are redrawn using the cached layout;
7. the frame reports `.partialDamage`, region count, and restored pixel count.

Full-scene rendering remains mandatory for:

- cold cache creation;
- resize;
- theme or mode generation mismatch;
- transient overlays;
- selection autoscroll;
- any non-animation invalidation.

## Delivery integrity

This overlay includes four independent gates:

- exact baseline branch, HEAD, and blob verification before application;
- working-tree verification after patch application;
- staged-index verification before commit;
- committed-blob verification after commit.

The commit cannot be considered complete merely because tests compile. The
committed renderer and runtime blobs must differ from the known old blobs and
contain the required partial-damage literals.
