# C2.5D — Frame-path diagnostics and cold-start stabilization

This checkpoint implements the first bisectable half of renderer invalidation
hardening.

## Runtime contract

Every scene may now report:

- invalidation class;
- render path;
- cache-miss reason;
- layout time;
- cache-restore time;
- static-scene time;
- dynamic-scene time;
- overlay time.

`LunaFrameTimingStats` records path counts, cache-miss counts, the latest report,
and a cache-hit rate over cache-eligible frames.

## Kitchen Sink behavior

The Kitchen Sink reports full-scene versus cached-animation frames. Its first
cold frame does not advance the bouncing-square clock while the static scene is
being built. Once the static cache is stored, the animation clock is reset and
steady animation begins from a clean timing origin.

This checkpoint does not add a render thread. UI mutation, rendering, and
presentation remain single-lane and deterministic.

## Remaining C2.5D integration

The established `.partialDamage` path is reserved for the next bisectable
checkpoint:

- dirty-region restoration;
- old/new square-bound damage;
- caret and selection damage;
- region-aware overlay invalidation.
