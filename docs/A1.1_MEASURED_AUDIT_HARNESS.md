# A1.1 — Measured Audit Harness

A1.1 adds observational, product-neutral measurement support without changing
Luna's accepted C2.4 runtime or text-layout behavior.

## Added public surfaces

- `LunaA1AuditRecorder`
- `LunaA1AuditSnapshot`
- `LunaA1CountingGeometryProvider`
- `LunaA1StaticTextAudit`
- `LunaA1FramebufferAudit`

The recorder is opt-in. Normal Luna call sites are unchanged. This is deliberate:
A1.1 must measure the current implementation before C2.5 is approved.

## Interpretation

`logicalLinesPresentedToLayout` records the complete document line count supplied
to each measured layout call. Geometry-provider counts reveal repeated complete-line
and suffix shaping requests. Framebuffer wrappers report exact byte and pixel counts
for audit-controlled operations.

A1.1 does not claim that the scalability defect is fixed.
