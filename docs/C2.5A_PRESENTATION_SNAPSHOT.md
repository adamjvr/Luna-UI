# C2.5A — Presentation Snapshot and Unwrapped Viewport Plan

## Purpose

C2.5A introduces the revision-stable presentation object and the arithmetic
unwrapped viewport plan needed to remove whole-document work from the normal
unwrapped rendering path.

This checkpoint is deliberately additive. It establishes a reviewed API that Moth
can consume before the existing `LunaStaticTextView` implementation is switched to
the new planner in C2.5A integration.

## New contracts

### `LunaStaticTextPresentationSnapshot`

One immutable logical document per product-owned revision. Multiple panes and the
minimap may share the same object by reference identity.

The snapshot does not own:

- scroll position;
- caret or selection;
- viewport bounds;
- wrap width;
- pane focus.

Those values remain pane-local.

### `LunaUnwrappedViewportPlan`

Derives in constant time:

- visible logical range;
- bounded overscan range;
- total visual rows;
- maximum scroll position.

Only `visible rows + overscan` need geometry materialization. A 50,000-line
document with 40 visible lines and three rows of overscan on each side materializes
46 lines.

## Complexity

| Operation | Complexity |
|---|---:|
| Plan viewport | O(1) |
| Materialize planned lines | O(V + O) |
| Total document scan | None |
| Total document shaping | None |

`V` is visible rows and `O` is bounded overscan.

## Next integration checkpoint

The next Luna checkpoint replaces the `.none` branch inside
`LunaStaticTextView.layout()` with this plan while preserving scrollbar geometry,
caret, selection, highlights, hit testing, and accessibility. Soft wrapping remains
on the existing path until the single-shape wrap-record checkpoint.
