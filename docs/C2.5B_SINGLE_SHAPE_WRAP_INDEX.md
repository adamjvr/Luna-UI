# C2.5B — Single-Shape Soft-Wrap Records

The existing soft-wrap path repeatedly shapes progressively shorter suffixes of a
logical line. C2.5B introduces an immutable wrap index built from insertion
positions in one complete shaped geometry.

The new algorithm:

1. shapes one complete logical line;
2. records grapheme-safe UTF-8 boundaries;
3. uses binary search over complete-line insertion positions;
4. prefers the last fitting whitespace boundary;
5. emits contiguous half-open UTF-8 ranges.

Normal CI can assert deterministic operation counts through
`LunaStaticTextWrapBuildDiagnostics`. Wall-clock pathological tests remain opt-in.

This checkpoint adds the reusable index. The subsequent integration checkpoint
replaces `LunaStaticTextView.visualSegments` suffix shaping with these records.
