# Luna C2.5D2R2 native acceptance

Run:

```bash
swift run LunaUITestApp -- --kitchen-sink
```

Confirm all of the following:

- the cold frame draws the complete scene;
- the next steady animation frames report `partialDamage`;
- the normal damage set contains the old square, new square, and HUD;
- the square leaves no trails;
- the HUD does not retain stale digits or text;
- steady partial frames do not rebuild general scene layout;
- opening a menu or quick panel forces `fullScene`;
- closing the overlay returns to `partialDamage`;
- resizing produces one complete cache rebuild and then returns to
  `partialDamage`;
- theme switching invalidates the old cache;
- selection autoscroll never uses the animation-only fast path.

Also run:

```bash
swift run LunaUITestApp -- --editor
```

Confirm the event-driven editor baseline still launches and does not request
continuous animation frames.
