# Apply and validate Luna C2.5D2

Start from the committed C2.5D branch state:

```bash
cd ~/GitHub/Luna-UI
git switch a1.1-measured-audit
git pull --ff-only
git status --short
```

The status output should be empty before applying the overlay.

```bash
unzip -o \
  ~/Downloads/Luna-UI-C2.5D2-Repository-Overlay.zip \
  -d .

git apply --recount --check \
  patches/C2.5D2_PARTIAL_DAMAGE_INTEGRATION.patch

git apply --recount \
  patches/C2.5D2_PARTIAL_DAMAGE_INTEGRATION.patch
```

Validate:

```bash
git diff --check

swift test \
  --filter LunaC25D2PartialDamageTests

swift build
swift test
./scripts/validate-iteration.sh
```

Native checks:

```bash
swift run LunaUITestApp -- --kitchen-sink
swift run LunaUITestApp -- --editor
```

Expected Kitchen Sink behavior:

- the first frame is a complete static-cache build;
- steady animation reports `partialDamage`;
- steady animation performs no complete scene-layout build;
- opening a menu or overlay falls back to `fullScene`;
- closing it returns to `partialDamage`;
- resizing rebuilds the cache once and then returns to `partialDamage`.

Review and commit:

```bash
git status --short
git diff --check
git diff --stat

git add \
  Sources/LunaHostCore/LunaFramePathDiagnostics.swift \
  Sources/LunaHostCore/LunaFrameRuntime.swift \
  Sources/LunaRender/LunaFramebuffer.swift \
  Sources/LunaUITestApp/DemoSharedRenderer.swift \
  Tests/LunaUIConvergenceC1BTests/LunaC25D2PartialDamageTests.swift \
  docs/C2.5D2_PARTIAL_DAMAGE_RENDERING.md \
  C2.5D2_BASELINE.md \
  C2.5D2_APPLY_AND_TEST.md

git diff --cached --check
git diff --cached --stat
git commit -m "perf(render): add C2.5D2 partial damage"
git push origin a1.1-measured-audit
```
